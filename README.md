# Rubik's Cube Portfolio

A static personal portfolio built with plain HTML, CSS and JavaScript. The homepage is an interactive 3D cube made with CSS transforms; each of its six faces opens one portfolio page. No frameworks, no build step, no API keys.

## Structure

```
index.html            Homepage with the cube
about.html            01 · About Me        (red)
education.html        02 · Education       (blue)
projects.html         03 · Projects        (yellow)
achievements.html     04 · Achievements    (green)
activities.html       05 · Activities & Interests (orange)
goals.html            06 · Future Goals    (off-white)
css/styles.css        Shared design system, cube styling
js/content.js         ★ ALL your personal content lives here
js/site.js            Header, footer, helpers
js/render.js          Builds the six content pages from content.js
js/home.js            Homepage navigation lists
js/cube.js            Cube: drag, keyboard, buttons, face links
assets/               Favicon and an images/ folder for your pictures
```

## Make it yours

Open **`js/content.js`** and replace everything in `[SQUARE BRACKETS]`. Placeholders are highlighted in yellow on the page so you can see what is left. To remove the highlight once you are done, delete the `.ph-text` rule in `css/styles.css`.

- **Photos / screenshots:** put files in `assets/images/` and set `image.src` (e.g. `"assets/images/portrait.jpg"`). Leave `src` empty to keep the placeholder box.
- **Projects:** each project supports a summary, technologies, any number of screenshots, and optional `links.github` / `links.demo` (links only show when filled in).
- **Add or remove entries:** copy or delete objects inside the arrays. Block types available: `text`, `split`, `facts`, `chips`, `timeline`, `entries`, `groups`, `projects`, `interests`, `list`.
- **Change which colour/face a section uses:** edit `color` and `face` in `sections` (keep each unique).

## Run locally

Opening `index.html` by double-clicking works in most browsers. For the most reliable result use a tiny local server:

```bash
cd rubik-portfolio
python3 -m http.server 8000
# then open http://localhost:8000
```

(or `npx serve`, or the VS Code "Live Server" extension).

## Deploy to GitHub Pages

1. Create a repository on GitHub (e.g. `portfolio`) and upload the **contents** of this folder, so `index.html` is at the repository root.
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/portfolio.git
   git push -u origin main
   ```
2. On GitHub open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and folder **/ (root)**, then **Save**.
4. After a minute your site is live at `https://<your-username>.github.io/portfolio/`.

All URLs in the project are relative, so the repository sub-path works without changes. The empty `.nojekyll` file tells GitHub Pages to serve the files as they are.

## Using the cube

- **Drag** (mouse or touch) to rotate. A drag never opens a page.
- **Click / tap a face** to open its page. A face always links to its own section, in any orientation.
- **Keyboard:** Tab to the cube, use the arrow keys to turn it one face at a time, **Home** to reset, **Enter** to open the face in front. Buttons below the cube do the same.
- The compact menu next to the cube, the header menu, and the index below the fold are always-available alternatives.
- Respects `prefers-reduced-motion` (no turning animation). The cube never spins by itself.

## Limitations and browser notes

- Targets current Chrome, Edge, Firefox and Safari (including iOS). Uses CSS 3D transforms, Pointer Events and `color-mix()` (with a fallback for older browsers).
- The page content is generated by JavaScript from `content.js`, so with JavaScript disabled visitors only see the navigation links, not the page text. Search engines that do not run JavaScript will see little content; if SEO matters, copy your final text into the HTML.
- On touch devices, touching the cube area rotates it instead of scrolling the page, so the cube is kept moderately sized and the rest of the page remains scrollable.
- The cube is a navigation element, not a puzzle: there are no layer turns or solving logic.
- Fonts are system fonts, so typography varies slightly between operating systems.
